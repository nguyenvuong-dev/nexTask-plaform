# nexTask-plaform

A Microservices-Based Intelligent Productivity Platform

## Overview

NexTask is a productivity management platform that combines task planning, sprint management, AI assistance, smart notifications, and productivity analytics into a unified ecosystem.

## Tech Stack

- Spring Boot
- Python
- PostgreSQL
- Redis
- Kafka
- RabbitMQ
- Docker
- Kubernetes

## Core Features

- Task Management
- Kanban Board
- Sprint Planning
- AI Assistant
- Smart Reminder
- Productivity Analytics
